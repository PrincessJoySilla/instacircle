# InstaCircle ✿

A privacy-focused Instagram follower analytics web application.

InstaCircle helps users analyze their Instagram connections by comparing their followers and following lists.

## Features

- Identify users who don't follow you back
- Find mutual followers
- Identify followers you don't follow back
- Detect recent unfollowers using previous data exports
- Search and filter usernames
- Upload Instagram JSON exports

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Privacy

InstaCircle processes Instagram data locally in the browser. It does not require Instagram login credentials.
